# Contributing

Thanks for your interest in improving GateNet! To keep the project healthy, please follow these steps:

1. Create an issue describing the change or bug.
2. Fork and branch from `main`.
3. Write clear commits with tests where possible.
4. Run the CI commands locally (`npm test` in `api/` and `web/`).
5. Open a pull request with a concise summary and screenshots for UI changes.

## Coding guidelines
- Prefer small, focused PRs.
- Add or update docs when behavior changes.
- Keep configuration in `.env` files and never commit secrets.
